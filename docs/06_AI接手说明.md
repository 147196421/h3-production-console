# AI接手说明

## 1. 接手任务前必须读取

```text
docs/00_项目交接总览.md
docs/01_项目圣经与全剧总纲.md
docs/02_人物档案与人物弧.md
docs/03_全剧60集分集大纲.md
docs/04_视觉声音与年代规范.md
docs/05_H3生产与首尾帧规范.md
docs/07_资产索引与备份清单.md
```

处理某一集时，再读取上一集已完成任务、最终成片尾帧和当前集资产。不能只读取当前一条提示词。

## 2. 允许AI完成的工作

- 把既定分集大纲扩写成8—12段H3任务。
- 为新角色、场景、道具提出资产需求。
- 根据真实成片尾帧修正下一镜开头。
- 在不改变因果和人物弧的前提下优化对白与节奏。
- 记录失败原因，生成只改一个问题的重做提示词。
- 更新任务JSON、资产索引和制作状态。

## 3. 未经确认不得修改

- 60集总规模和最终结局。
- 明日收音机的八条规则。
- 林国强、苏清禾和林小满的核心人物弧。
- 周永发依法落网的解决方式。
- 已经通过验收的成片事实、人物服装和固定场景布局。
- 项目标题、年代和3D写实国漫方向。

## 4. 扩写一集的标准交付

每集必须交付：

1. 本集一句话目标。
2. 开头承接点。
3. 8—12个任务，单段不超过15秒。
4. 每段标题、时长、镜头类型。
5. 每段所需参考图及准确文件名。
6. 按秒H3提示词。
7. 后期对白、旁白和环境声。
8. 结尾状态及下一镜衔接方式。
9. 本集新增资产清单。
10. 本集结尾钩子。

## 5. 任务JSON字段

```json
{
  "id": "EP02-C01",
  "episode": 2,
  "clip": 1,
  "title": "抱起收音机",
  "duration": 8,
  "shot_type": "尾帧续拍",
  "reference_hint": "EP01-C10尾帧；林国强三视图；林家土屋夜景首帧",
  "prompt": "按秒提示词",
  "dialogue": "后期配音文字",
  "continuity": "片段结束时人物、道具、机位和光线状态"
}
```

## 6. 写作自检

- 本集事件是否来自60集大纲，而不是另开支线？
- 主角是否通过行动解决问题，而非只靠新闻答案？
- 苏清禾是否有独立判断和实际工作？
- 家庭关系是否按阶段推进，没有突然和好或突然翻脸？
- 周永发是否有合理利益和手段，而非无意义找茬？
- 1998年物件、制度和说话方式是否可信？
- 钩子是否能自然带入下一集？
- 每个`@图片`是否在对应镜头中存在且位置正确？

## 7. 面向视频模型的禁止事项

- 不把“使用方法”复制进成品提示词。
- 不把所有`@图片`统一堆到开头。
- 不把后期对白当成画面文字生成。
- 不让模型生成可读新闻、日期、字幕或招牌；这些后期添加。
- 不用一张人物三视图同时要求多个完全不同年龄或服装版本。
- 不以预生成尾帧替代真实视频尾帧。

道具位置：

任何AI结束工作前必须填写一次，不得只说“已经完成”。
