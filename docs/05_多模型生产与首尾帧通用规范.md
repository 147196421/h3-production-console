# 多模型生产与首尾帧通用规范

本文件只规定H3、Grok及后续视频模型共同遵守的生产流程、参考图、首尾帧和验收规则。模型各自的运镜、动作节奏与适配限制统一写在`docs/11_H3与Grok模型执行规范.md`，不得从本文件标题推断某个模型优先。

## 1. 基本流程

1. 先确认上一集是否完成成片验收；未完成时只能进行下一集预制作，不标记“可生产”。
2. 从分集大纲提取本集唯一核心目标，并核对上一集最后剧情状态。
3. 拆成8—12个5—15秒任务。
4. 为每个任务设置`shot_type`、参考图、按秒提示词、对白、结尾状态。
5. 在视频生成平台上传本镜需要的图片。
6. 把提示词复制到唯一输入框，在原位置用平台真正的`@引用参考图`替换文字文件名。
7. 生成后检查，不合格则记录原因并重做。
8. 合格视频上传制作台，离线提取首帧与尾帧。
9. 根据下一镜类型决定是否继承尾帧，并更新场景持续状态。

每个任务在写提示词前必须先记录四项：输入状态、可见动作、输出状态、下一镜连接方式。提示词不是独立短片描述，而是完整一集中前后相连的状态变换。

同一地点还必须维护“场景状态账本”：空间骨架、当前持久物件、物件位置、最近一次改变它的镜头。母版只锁定房间尺寸和基础布置；新增物件不会自动写入母版，也不能在后续随机消失。详细分层规则以`docs/04_视觉声音与年代规范.md`为准。

## 2. 三种镜头类型

### 尾帧续拍

适用：同场景、同景别或相近景别、同一动作连续发展。

下一镜必须引用`@上一镜尾帧.jpg`，并在0秒段说明姿势、机位、光线和运动方向保持一致。EP01中C01→C02属于此类。

### 新首帧

适用：正常切镜、正反打、远近景转换、闪回、时间跳跃、地点变化。

不用上一镜尾帧强绑构图，应使用人物三视图、固定场景和专用构图首帧。上一镜尾帧仍保存备查。

### 标准人物/道具图

适用：人物特写、手部与道具动作、物件插入镜头。使用人物三视图或道具三视图锁定身份，不必强制继承上一镜完整画面。

## 3. 剧情连续与画面续拍的区别

- “剧情连续”是硬要求：人物、道具、时间、位置和因果必须接得上，所有镜头都要做到。
- “尾帧续拍”只是生成方法：只有同机位或连续运镜时才用上一镜尾帧锁定画面。
- 新机位可以不用上一镜尾帧，但提示词仍必须复述上一镜输出状态，并用专用构图图建立新角度。
- 剪辑中的正常硬切不等于人物可以瞬移。切换机位前，人物必须已经进入场景，道具必须已经被拿入画面，位置变化必须有可见动作。
- 声音桥可以跨机位维持连续，例如上一镜结尾先听见门声，下一镜才看到门打开。

### 人物与道具首次出现规则

1. 上一镜不存在、下一镜出现的人物，必须展示从门、画外或明确路径进入。
2. 上一镜没有的随身道具，必须由人物携带进入、从已建立位置取出，或在更早镜头提前出现。
3. 人物从A点到B点必须写起点、路径和终点；不能只在下一镜直接改变站位。
4. 近景切回全景时，要恢复前一全景建立的左右关系，禁止镜像。
5. 生成后的真实成片与文字冲突时，以成片为准，先改下一镜，不得假设观众看见了没有生成出来的动作。

## 4. 尾帧离线提取

制作台使用FFmpeg完成，不需要AI API：

- 开头候选：约0.05秒、0.25秒、0.5秒。
- 尾部候选：结束前1.2秒、0.9秒、0.6秒、0.35秒、0.15秒。
- 评分指标：黑屏惩罚、亮度、局部对比度、边缘细节。
- 输出：`EPxx_Cxx_首帧.jpg`和`EPxx_Cxx_尾帧.jpg`。

离线算法只判断画面质量，不理解闭眼、微表情或剧情姿势。重要尾帧应由人工复核。后续可增加“五张候选图＋人工点选”，视觉AI只作为可选辅助。

## 5. `@参考图`写法

- `@文件名`必须放在真正发挥作用的位置，不统一堆在开头。
- 场景母版放在【画幅与风格】或0秒建立镜头。
- 构图首帧放在第一个时间段，负责站位和机位。
- 人物三视图放在人物首次清晰出现的时间段。
- 道具三视图放在道具首次成为主体的时间段。
- 上一镜尾帧放在0秒，优先级高于场景母版。
- 同一张图不在一条提示词里重复引用。
- 天气、损坏或布置变化参考图放在变化实际发生的秒段，例如EP02-C09的雨滴图只能在6—8秒出现，不能放到0秒让模型提前下雨。

示例：

```text
【0-1秒】严格承接当前模型尾帧（H3为 @EP01_C01_H3_尾帧.jpg，Grok为 @EP01_C01_GROK_尾帧.jpg）的人物姿势、机位和月光方向；
同时用 @林国强_三视图.jpg 锁定五官、发型和深蓝旧工装夹克。
```

## 6. 单镜提示词结构

```text
【画幅与风格】9:16、3D写实国漫、年代、地点、主光源、场景母版。
【0-X秒】构图首帧、人物起始姿势、景别和焦段。
【X-X秒】动作发展、镜头运动、焦点变化。
【X-X秒】情绪反应或信息揭示。
【最后时段】明确停在什么姿势、看向哪里、哪个物件留在何处。
【结尾状态】供下一镜读取的连续性记录。
【统一质量】身份、服装、材质、物理动作和禁止项。
```

## 7. 提示词密度

- 每秒只要求一个主要可见变化。
- 不写无法同时看见的心理活动，用眼神、停顿、握手、退步等可视动作表达。
- 焦段、景别和运镜只写会影响画面的参数，不堆摄影术语。
- 不在同一15秒内要求换地点、换服装、多人长对白和复杂打斗。
- 提示词长不是目标；动作顺序无歧义才是目标。

## 8. 单镜验收清单

- 人脸与三视图一致。
- 年龄、发型、服装颜色一致。
- 人数正确，无重复人物。
- 手指、手腕、接触关系正常。
- 场景左右关系没有镜像。
- 道具造型没有变化。
- 动作完成在规定时间内，末尾没有突然重置。
- 没有现代物件、乱码、字幕、Logo和水印。
- 尾帧清晰、非闭眼、非运动模糊，并适合需要时续拍。
- 新出现的人物有明确入口，新出现的道具有明确来源。
- 上一镜输出位置与本镜输入位置一致；若变化，镜头内已完整展示移动过程。
- 本镜结尾动作能够真实启动下一镜，而不是只写“为下一镜铺垫”。
- 当前色温变化有时间、地点或天气依据，并匹配项目视觉指纹。
- 场景新增物件来自明确入口，持续物件没有无故消失，长期变化已经写入状态账本。

## 9. 单集开拍门禁

进入本集C01正式生成前，逐项确认：

```text
上一集最终通过镜头：
上一集最后可见剧情状态：
上一集是否以黑场结束：
本集C01是尾帧续拍还是新首帧：
本集当前模型：H3 / Grok
场景骨架母版：
上一集遗留的持续物件及位置：
本集新增固定资产是否已经验收：
本集提示词是否标记为可生产：
```

任何一项不确定，只能保留草稿或预制作资产，不得直接生成连续性依赖镜头。

## 10. 失败记录格式

```text
任务：EPxx-Cxx
失败位置：第X—X秒
问题类型：变脸/手部/构图/服装/场景/运动/年代/文字
具体表现：只写可见问题
重做要求：保留哪些正确部分，只修改哪一项
使用参考图：@文件名列表
```

## 11. 文件命名

- 人物：`姓名_三视图.jpg`
- 固定场景：`地点_时间_母版.jpg`
- 构图：`人物或事件_景别_首帧.jpg`
- 道具：`年代_道具名_三视图.jpg`
- 视频：`EP01_C01.mp4`
- 首尾帧按模型命名，例如`EP01_C01_H3_首帧.jpg`、`EP01_C01_H3_尾帧.jpg`或`EP01_C01_GROK_首帧.jpg`、`EP01_C01_GROK_尾帧.jpg`

禁止使用“最终版2”“新新版本”“图片123”等无法交接的名字。
