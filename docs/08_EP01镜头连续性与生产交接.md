# EP01镜头连续性与生产交接

## 1. 本文件用途

本文件是第一集逐镜生产的权威连续性表。任何人或AI接手EP01时，必须先读本文件，再打开制作台核对真实成片和尾帧。不得依赖聊天记录补全人物入口、道具来源或空间关系。

当前支持H3与Grok两条独立生产轨。人物图、场景图、剧情和本表的输入/输出状态共用；专用运镜、提示词执行层、成片和真实尾帧分开。若从已完成两个H3镜头改为使用Grok，Grok轨必须从C01重新生成，不能让Grok的C03直接继承H3的C02。

第一集总时长90秒，共10段。地点始终是黎明前的林家土屋，除C07主观记忆闪回外不换场。

## 2. 固定空间与初始状态

- 旧木床在左墙，木格窗在后墙偏左，木桌在右侧，日历在右墙木桌上方，木门在画面右侧。
- 收音机和煤油灯从第一镜起都在右侧木桌，不得换位。
- 冷蓝月光从后左进入，煤油灯提供微弱暖光，整集保持同一黎明前时刻。
- C01开始时屋内只有林国强；苏清禾和林小满在门外或外屋，C03才从右门进入。
- 苏清禾进入时提着已经收拢的旧布包；小满进入时一手抱旧布娃娃、一手抓母亲衣角。

## 4. 动态尾帧使用规则

- C02的0秒只能引用当前模型真实尾帧：H3用`@EP01_C01_H3_尾帧.jpg`，Grok用`@EP01_C01_GROK_尾帧.jpg`。
- C03的0秒同理优先引用当前模型的真实C02尾帧，再用人物三视图锁脸；默认不跨模型续拍。
- `@林家土屋收包袱双人首帧.jpg`只能在C03的6—8秒使用，负责妻女进屋后的站位，不能放在开头替代真实尾帧。
- C04—C10主要是正常机位切换、物件插入或匹配切，不使用上一镜尾帧强绑构图，但必须继承本表的输出状态。

## 5. 已有成片处理

- 用户已生成C01、C02，画面中均只有林国强，符合当前人物出场逻辑，不因提示词升级强制重做。
- C02若没有门外脚步和布料声，在后期音轨补入即可；视觉上只要结尾林国强在木桌旁看向右侧，就可直接进入C03。
- C03尚未生成时必须使用V1.9提示词。若实际C02尾帧的视线、站位与文字不同，以真实尾帧改写C03的0—2秒，后续妻女仍必须从明确入口进入。

## 6. 每镜生成前检查

1. 对照上一镜真实尾帧确认人数、左右位置、手势和视线。
2. 对照本表确认本镜新增人物与道具的来源。
3. 只下载本镜列出的参考图，并在提示词对应时间段逐个`@`引用。
4. 确认镜头结尾能够产生本表规定的输出状态。
5. 生成后若模型省略了关键进入动作、拿取动作或位置变化，该片段直接判定不合格，不能靠剪辑掩盖。
