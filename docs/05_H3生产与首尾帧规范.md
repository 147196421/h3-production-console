# H3生产与首尾帧规范

## 1. 基本流程

1. 从分集大纲提取本集唯一核心目标。
2. 拆成8—12个5—15秒任务。
3. 为每个任务设置`shot_type`、参考图、按秒提示词、对白、结尾状态。
4. 在好漫剧上传本镜需要的图片。
5. 把提示词复制到唯一输入框，在原位置用平台真正的`@引用参考图`替换文字文件名。
6. 生成后检查，不合格则记录原因并重做。
7. 合格视频上传制作台，离线提取首帧与尾帧。
8. 根据下一镜类型决定是否继承尾帧。

## 2. 三种镜头类型

### 尾帧续拍

适用：同场景、同景别或相近景别、同一动作连续发展。

下一镜必须引用`@上一镜尾帧.jpg`，并在0秒段说明姿势、机位、光线和运动方向保持一致。EP01中C01→C02属于此类。

### 新首帧

适用：正常切镜、正反打、远近景转换、闪回、时间跳跃、地点变化。

不用上一镜尾帧强绑构图，应使用人物三视图、固定场景和专用构图首帧。上一镜尾帧仍保存备查。

### 标准人物/道具图

适用：人物特写、手部与道具动作、物件插入镜头。使用人物三视图或道具三视图锁定身份，不必强制继承上一镜完整画面。

## 3. 尾帧离线提取

制作台使用FFmpeg完成，不需要AI API：

- 开头候选：约0.05秒、0.25秒、0.5秒。
- 尾部候选：结束前1.2秒、0.9秒、0.6秒、0.35秒、0.15秒。
- 评分指标：黑屏惩罚、亮度、局部对比度、边缘细节。
- 输出：`EPxx_Cxx_首帧.jpg`和`EPxx_Cxx_尾帧.jpg`。

离线算法只判断画面质量，不理解闭眼、微表情或剧情姿势。重要尾帧应由人工复核。后续可增加“五张候选图＋人工点选”，视觉AI只作为可选辅助。

## 4. `@参考图`写法

- `@文件名`必须放在真正发挥作用的位置，不统一堆在开头。
- 场景母版放在【画幅与风格】或0秒建立镜头。
- 构图首帧放在第一个时间段，负责站位和机位。
- 人物三视图放在人物首次清晰出现的时间段。
- 道具三视图放在道具首次成为主体的时间段。
- 上一镜尾帧放在0秒，优先级高于场景母版。
- 同一张图不在一条提示词里重复引用。

示例：

```text
【0-1秒】严格承接 @EP01_C01_尾帧.jpg 的人物姿势、机位和月光方向；
同时用 @林国强_三视图.jpg 锁定五官、发型和深蓝旧工装夹克。
```

## 5. 单镜提示词结构

```text
【画幅与风格】9:16、3D写实国漫、年代、地点、主光源、场景母版。
【0-X秒】构图首帧、人物起始姿势、景别和焦段。
【X-X秒】动作发展、镜头运动、焦点变化。
【X-X秒】情绪反应或信息揭示。
【最后时段】明确停在什么姿势、看向哪里、哪个物件留在何处。
【结尾状态】供下一镜读取的连续性记录。
【统一质量】身份、服装、材质、物理动作和禁止项。
```

## 6. 提示词密度

- 每秒只要求一个主要可见变化。
- 不写无法同时看见的心理活动，用眼神、停顿、握手、退步等可视动作表达。
- 焦段、景别和运镜只写会影响画面的参数，不堆摄影术语。
- 不在同一15秒内要求换地点、换服装、多人长对白和复杂打斗。
- 提示词长不是目标；动作顺序无歧义才是目标。

## 7. 单镜验收清单

- 人脸与三视图一致。
- 年龄、发型、服装颜色一致。
- 人数正确，无重复人物。
- 手指、手腕、接触关系正常。
- 场景左右关系没有镜像。
- 道具造型没有变化。
- 动作完成在规定时间内，末尾没有突然重置。
- 没有现代物件、乱码、字幕、Logo和水印。
- 尾帧清晰、非闭眼、非运动模糊，并适合需要时续拍。

## 8. 失败记录格式

```text
任务：EPxx-Cxx
失败位置：第X—X秒
问题类型：变脸/手部/构图/服装/场景/运动/年代/文字
具体表现：只写可见问题
重做要求：保留哪些正确部分，只修改哪一项
使用参考图：@文件名列表
```

## 9. 文件命名

- 人物：`姓名_三视图.jpg`
- 固定场景：`地点_时间_母版.jpg`
- 构图：`人物或事件_景别_首帧.jpg`
- 道具：`年代_道具名_三视图.jpg`
- 视频：`EP01_C01.mp4`
- 首尾帧：`EP01_C01_首帧.jpg`、`EP01_C01_尾帧.jpg`

禁止使用“最终版2”“新新版本”“图片123”等无法交接的名字。
