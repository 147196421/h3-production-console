# H3与Grok模型执行规范

## 1. 核心原则

制作台中的“剧情任务”是共同底稿，包含人物、事件、按秒动作、对白和结尾状态；“模型提示词”和“生成结果”按H3、Grok分别处理。切换模型不会改写剧情事实，只会切换模型专用执行要求、当前模型的任务状态、成片、首帧和尾帧。

禁止把两个模型的结果当成同一条连续轨道。H3镜头默认只继承H3上一镜尾帧，Grok镜头默认只继承Grok上一镜尾帧。

## 2. 前台操作

1. 在制作台顶部选择H3或Grok。
2. 打开镜头后，复制当前模型显示的“专业单框提示词”。
3. 下载参考图，在提示词每个`@文件名`出现的位置选择同名图片。
4. 在第三方生成平台选择与任务一致的5秒、10秒或15秒时长和9:16比例。
5. 生成完成后回到制作台，确认顶部仍是刚才使用的模型，再上传视频。
6. 系统把该视频和首尾帧写入当前模型分轨；切换到另一模型不会看到或覆盖这份结果。

## 3. 共用事实层

两种提示词必须共同保留：剧情因果、按秒时间轴、人物与场景参考图、结尾状态、年代限制、3D写实国漫视觉规范。

H3与Grok必须共享同一套项目视觉指纹和固定参考资产。切换模型只允许改变运镜、动作拆分、表演节奏和模型适配措辞，不允许改变脸型、身材、服装主色、场景骨架、持续物件、PBR材质、年代色盘或剧情光线。视觉指纹和场景三层状态规则以`docs/04_视觉声音与年代规范.md`为准。

每镜共用事实层必须先写完，再编写模型执行层。共用事实层至少包含：0秒输入状态、完整时间轴、人物入口、道具来源、空间轴线、可见动作因果、结尾状态、参考图准确文件名和禁止项。任何模型不得改写这些事实。

模型差异不是只替换“H3/Grok”字样；制作台会为EP01与EP02每个镜头注入当前模型专用运镜，再加入模型级执行重点和质量控制。

## 4. H3专用执行规则

- 核心目标：在5—15秒内优先保证人物身份、构图、动作顺序、空间关系和首尾状态稳定。
- 时间执行：严格按秒段依次完成；一个时间段只承担一个主要动作或信息点，不提前执行下一段。
- 运镜选择：固定机位、稳定推拉、一次横移、一次摇镜或单次拉焦优先；避免同段同时环绕、变焦、快速转身和多人复杂走位。
- 动作设计：复杂动作拆成“准备—接触—完成—停稳”，让手与道具接触关系清晰；宁可动作稍慢，不得跳步。
- 转场策略：硬切、匹配切和声音桥必须在剧情时间轴中明确；模型不得自行增加闪回、慢动作或第二机位。
- 参考图策略：真实上一镜尾帧和构图首帧的约束优先；人物三视图用于锁身份，道具图用于锁结构，不要求模型同时重构过多视觉条件。
- 结尾要求：最后0.5—1秒尽量停稳，留下可辨识姿势、视线、道具位置和机位，便于下一镜续拍。
- 常见失败：段落间姿势重置、快速动作导致变脸、复杂群戏融合、手部跳变、镜头未停稳。出现时优先减少同段任务，不改变剧情事实。

## 5. Grok专用执行规则

- 核心目标：在剧情事实不变的前提下，利用运动惯性、视线动机、自然反应停顿和次级运动形成连续电影感。
- 时间执行：仍须严格覆盖全部秒段；“连续运镜”不等于可以打乱顺序、压缩人物入口或提前揭示后段信息。
- 运镜选择：镜头运动必须有可见动机，例如跟随视线、脚步、手部动作、声音方向或前景遮挡；无动机时保持稳定，不为炫技环绕。
- 动作设计：保留起势、接触、重量反馈、呼吸和反应延迟；布料、发丝、灰尘等次级运动应克制，不能遮盖主要动作。
- 焦点与景深：拉焦必须跟随故事注意力；焦点呼吸只作微量真实感，不能造成主体持续失焦。
- 转场策略：连续跟拍、轴线内侧移、匹配运动和声音引导可优先使用；只有任务明确要求时才能硬切或蒙太奇。
- 参考图策略：`@参考图`位置和H3完全遵循同一规则；Grok不得因运动能力较强而改变人物脸型、场景骨架、服装或持续物件。
- 结尾要求：连续运动必须在规定结尾状态前自然减速并停稳；下一镜若为续拍，只继承同一Grok分轨的真实尾帧。
- 常见失败：擅自增加机位、运镜过度、人物入场被省略、表演夸张、背景物件漂移。出现时减少运动幅度并强化0秒和结尾状态。

## 6. 模型选择建议

| 镜头需求 | 优先模型 | 原因 |
|---|---|---|
| 多个严格按序的小动作、拆装、道具接触 | H3 | 分段执行和构图稳定优先 |
| 视线带动、跟走、情绪反应、空间纵深 | Grok | 连续运动与自然停顿更有优势 |
| 高风险人物入场、关键剧情状态交接 | 先试H3 | 先确保因果完整，再决定是否制作Grok版本 |
| 已建立同模型尾帧链的连续镜头 | 保持当前模型 | 不跨模型自动继承尾帧 |

选择建议不是硬性质量排名。某一模型的实际成片更符合人物与连续性时，以人工验收结果为准；同一条连续分轨中途换模型必须从明确的新首帧或硬切点重新建立。

## 7. EP01逐镜双模型运镜

| 镜头 | H3版本 | Grok版本 |
|---|---|---|
| C01惊醒 | 眼睛特写、一次后拉、稳定半坐结尾 | 眼睛特写后拉、轻微呼吸感手持、自然稳定结尾 |
| C02日历 | 稳定横移、单次拉焦、分段读取信息 | 眼神驱动横移、弧线回脸、连续后退容纳下床 |
| C03入门 | 原机位右摇、轻微后拉、三人站稳 | 继承运动惯性、随视线右摇、平滑后移建立纵深 |
| C04小满 | 儿童眼平固定近景、极慢推近 | 前景遮挡、焦点呼吸、随儿童后缩轻推 |
| C05请求 | 固定三人中景、动作严格先后 | 克制半弧侧移、对白反应与视线引导 |
| C06收音机 | 稳定道具近景、接触后才发光 | 微距跟手、轻环绕、景深与反射渐变 |
| C07记忆 | 四个清晰短插入、亮点匹配切 | 同方向运动蒙太奇、光晕无缝转场 |
| C08机会 | 声音桥硬切、床边稳定中景 | 声音先入、硬切床边、前中后景 |
| C09沉默 | 固定三人同框、依次转头 | 缓慢弧形推进、逐个捕捉微反应 |
| C10新闻 | 收音机推近、切眼睛、黑场 | 视线匹配切、微距推进、切眼睛、黑场 |

上述差异只能改变表达方式，不能改变人物何时出现、从哪里进入、手中拿什么、对白意思和镜头结尾状态。

## 8. EP02逐镜双模型运镜

| 镜头 | H3版本 | Grok版本 |
|---|---|---|
| C01抱起收音机 | 稳定中近景慢推，倾听、检查、放回桌面依次完成，清楚留下双手和工具位置 | 轻微呼吸感推进，贴随倾听与克制晃动，顺势下降到桌面并停稳 |
| C02拆机检修 | 固定桌面轴线，小幅横移跟手，逐步完成螺丝、背板和内部检查 | 贴近桌面的短弧线串联取工具、卸背板和检查，景深跟随手眼 |
| C03听清碎片 | 手部近景与眼睛各一次拉焦，两次调谐之间明确停顿 | 从旋钮微距拉焦到眼睛，小幅回环到第二次微调，再随抬眼带向晴窗 |
| C04取包出门 | 稳定三人中景，问答、从挂钩取包、背包、跨门依次完成 | 轴线内侧移连接问答，随后贴随取包、背包和跨门全过程 |
| C05晴天到店 | 晴天外景稳定侧跟，先建立天气建筑，再完整表现上台阶和进门 | 从蓝天俯摇建立晴朗反差，低位侧跟脚步到门口，人物跨门后停在室外 |
| C06老板不信 | 柜台双人中景，视线摇向后仓电线再回人物，沿固定通道离开 | 横移建立柜台轴线，随视线滑向明线并返回，再平行跟随两人去后仓 |
| C07焦糊线路 | 稳定上摇看线、下摇取工具，清楚完成关闭闸刀 | 随人物仰视上摇到接点，利用门光展示纵深，再沿工具包动作下摇至闸刀 |
| C08解释危险 | 承接真实尾帧，近景检测后回双人中景，解释、收工具、离开依次完成 | 小幅推近展示检测证据，再后退成双人纵深，人物离开时保留未修线路前景 |
| C09第一滴雨 | 前6秒稳定双人中景，6秒后硬切唯一雨滴特写，再拉焦到人物 | 短距离随行回柜台，以云影改变光色，凉风引导雨滴微距并拉焦到相反反应 |

EP02的天气变化属于共用剧情事实：0—6秒仍是暴雨前压暗过程，`@第一滴雨落柜台_特写首帧.jpg`只能在6—8秒发挥作用。Grok不得为了电影感提前下雨，H3也不得把天气变化拆成互不连续的光线跳变。

## 9. 单框提示词组装顺序

后台复制出的H3或Grok成品提示词按以下顺序组成，模型名称和操作说明不得混入：

```text
本镜专用运镜
共用按秒剧情与就地@参考图
动作衔接约束
可见结尾状态
统一画面质量与禁止项
```

运镜层不能覆盖共用时间轴；若二者冲突，以当前集连续性文档中的剧情事实和输出状态为准。

## 10. 文件与数据隔离

- 上传视频：只在`data/tmp/uploads/`临时存在，首尾帧提取完成或失败后立即删除
- H3帧：`data/frames/h3/EPxx/EPxx_Cxx_H3_首帧.jpg`、`EPxx_Cxx_H3_尾帧.jpg`
- Grok帧：`data/frames/grok/EPxx/EPxx_Cxx_GROK_首帧.jpg`、`EPxx_Cxx_GROK_尾帧.jpg`
- SQLite表`task_outputs`以`task_id + model`为唯一键，分别记录首尾帧路径、提取时间和任务状态；新上传任务的`video_path`为空。

旧版本已有的单轨视频会迁移为H3分轨，不会自动复制成Grok结果。

V1.15起不再长期保存新上传的原视频。完全相同的视频在FFmpeg版本、提取算法和程序版本相同的情况下，会选择相同时间点和画面。旧版本已经保存的原视频不会在升级时自动删除，需要确认已备份后另行清理。

若用户之前只完成了EP01-C01和C02的H3版本，后来决定全片改用Grok，应切到Grok后从C01重新生成。后台会把Grok的C01、C02视为“待生成”，原H3成片保留在H3分轨中备查，不影响Grok从头建立连续尾帧链。

## 11. 尾帧衔接

若下一镜标记为“尾帧续拍”，当前模型上一镜上传完成后，下一镜参考素材会自动出现带模型后缀的真实尾帧，并且提示词中的引用同步变为对应文件名，例如：

- H3：`@EP01_C02_H3_尾帧.jpg`
- Grok：`@EP01_C02_GROK_尾帧.jpg`

若下一镜是“新首帧”或新机位硬切，不强制上传上一镜尾帧，但仍必须继承上一镜剧情输出状态，包括房间里已有的人、手中道具、站位方向、时间和光线。模型切换不能成为省略人物入场或道具来源的理由。

## 12. AI接管检查项

新AI扩写下一集或修订提示词前，必须完成以下检查：

1. 阅读项目交接总览、60集大纲、人物圣经、视觉规范、连续性文档和本规范。
2. 询问或确认本轮使用H3还是Grok。
3. 在后台查看该模型分轨最后一个通过验收的任务、成片和真实尾帧。
4. 不得根据另一模型“已完成”的状态推定当前模型也已完成。
5. 只有在用户明确要求跨模型衔接且人工验收画面可接时，才能手动使用另一模型尾帧；必须记录原因，系统默认不自动执行。
6. 上一集未验收时，下一集只能保留预制作提示词；门禁通过前不得把连续性依赖镜头标记为可生产。
7. 检查每个`@参考图`的时间位置：尾帧在0秒，人物在首次清晰出现处，道具在成为主体处，天气图在天气真正改变处。

## 13. 提示词与页面修正规则

模型名称、稳定分段等界面标签只显示在复制框外。复制内容包含实际运镜、按秒动作、结尾状态和画面要求。不得把模型名称标题或操作步骤加入生成文本。

按秒剧情是镜头事实依据：C01眼睛特写后拉；C07电子管→电路板→维修双手→旧修理铺→现实；C08声音桥后硬切床边；C09林国强→苏清禾→小满依次转头；C10收音机→眼睛→最后0.3秒黑场。模型运镜不得改写以上顺序。C10黑场不能用作第二集首帧，第二集应另建抱起收音机的新机位。

页面导航正常占位，手机和平板不覆盖提示词；上传期间暂时锁定模型和镜头选择，避免成片归错轨。切换模型保留当前镜头。HTTP环境复制使用浏览器兼容方式。
