# 人物档案与人物弧

## 林国强

- 年龄：36岁。
- 身份：无线电维修工出身，开局靠零散收废品维生。
- 外形锚点：短黑发、疲惫瘦削、褪色深蓝旧工装夹克、米色衬衣、深色长裤、黑布鞋。
- 核心能力：听声判断电器故障、拆解分类、维修焊接、现场应变。
- 核心缺陷：过去逃避责任、急躁、自尊脆弱，总想用一次大事证明自己。
- 需求：不是赚最多的钱，而是学会让家人长期感到安全。
- 人物弧：求一次原谅 → 接受不被相信 → 用规则约束自己 → 在无外挂时承担责任 → 成为可靠的丈夫、父亲和经营者。
- 台词风格：短句、具体、给方案；不说空泛鸡汤。典型句：“账摆桌上。哪一斤不对，我补。”
- 禁区：不能突然成为金融天才、商业演说家或无所不能的发明家。

## 苏清禾

- 年龄：32岁。
- 身份：会缝纫、记账和料理家务，后成为废品站财务与合同负责人。
- 外形锚点：低马尾、红色针织外套、米色衬衣、深灰长裤、黑布鞋。
- 核心能力：账目、观察人心、风险意识、谈判中的冷静。
- 核心伤口：一次次相信林国强又失望，最怕女儿重复自己的生活。
- 需求：有选择权、有稳定收入、女儿安全，而不是被丈夫“养着”。
- 人物弧：准备离开 → 暂缓观察 → 参与记账但保留退路 → 在危机中独立决策 → 成为共同经营者和真正平等的伴侣。
- 台词风格：清楚、直接、讲证据；温柔但不软弱。典型句：“我不是听你说，我看你怎么做。”
- 禁区：不能无条件原谅，不能沦为只负责哭泣和端饭的工具人。

## 林小满

- 年龄：6岁。
- 身份：林国强与苏清禾的女儿。
- 外形锚点：短黑波波头、姜黄色灯芯绒外套、暗红棉裤、黑布鞋、旧布娃娃。
- 核心特征：敏感、记忆细、说话直接，会注意成年人忽略的小细节。
- 人物弧：害怕父亲 → 允许父亲靠近 → 主动分享小事 → 在流言期仍坚持自己的观察 → 重新把“爸爸”当成安全的人。
- 台词风格：儿童短句，只说看到的事实，不替成年人总结道理。
- 禁区：不成人化、不承担破案主力、不长期置于危险中。

## 周永发

- 年龄：48岁。
- 身份：县城最大旧货商，控制灰色收购、压价、销赃和关系渠道。
- 外形锚点：发蜡整齐、微胖、棕色皮夹克、浅蓝衬衫、黑裤、金戒指。
- 核心能力：渠道、人情、价格操纵、抓住他人弱点。
- 核心信念：所有人都有价码，守规矩只是因为价钱不够。
- 人物弧：把林国强当小麻烦 → 价格围堵 → 利诱与栽赃 → 失控灭证 → 在完整证据链前失败。
- 台词风格：笑着说威胁，常用“都是做生意”“给你留条路”。
- 禁区：不大喊大叫、不亲自做所有脏活、不因为轻敌而突然变蠢。

## 陈大海

- 年龄：39岁。
- 身份：下岗搬运工、林国强旧识，后来负责上门回收和运输队。
- 外形锚点：寸头、结实、灰绿色旧工装、白背心、布鞋。
- 核心能力：力气、街坊关系、运输组织、讲义气。
- 核心缺陷：冲动、好面子、曾替周永发跑过一次不清楚来源的货。
- 人物弧：看热闹 → 临时帮忙 → 因旧过失被拿捏 → 主动坦白 → 成为团队最可靠的现场负责人。
- 台词风格：直、快、有烟火气，不能变成纯搞笑角色。

## 郑文博

- 年龄：64岁。
- 身份：退休无线电厂工程师。
- 外形锚点：灰发、圆框眼镜、深灰中山装、黑布鞋。
- 核心能力：电器标准、安全规范、材料辨识、行业信誉。
- 核心信念：修东西先保人，做生意先留记录。
- 人物弧：观察林国强 → 技术考验 → 建立标准 → 在案件中提供专业证据 → 把修复车间交给年轻人。
- 台词风格：精确、克制，很少夸人。典型句：“能亮不叫修好，安全才叫修好。”

## 何秀英

- 年龄：59岁。
- 身份：林国强母亲，独居乡下，做过集体食堂和农活。
- 外形锚点：灰黑发髻、深蓝棉袄、棕色旧裤、黑布鞋。
- 核心作用：家庭道德坐标，不替儿子向儿媳索要原谅。
- 人物弧：对儿子失望 → 帮忙但不袒护 → 认可苏清禾的经营能力 → 在流言期守住家门和孩子 → 看见儿子真正成人。
- 台词风格：朴素、硬，不绕弯。典型句：“你欠她们的，不是三句话，是往后的日子。”

## 高峰

- 年龄：30岁。
- 身份：县公安机关负责经济与治安线索的干警。
- 外形锚点：短发、1990年代橄榄绿制服、棕色腰带、黑皮鞋。
- 核心能力：现场勘查、证据意识、依法推进调查。
- 核心作用：既不是主角的私人保镖，也不是故意拖延的障碍；他只相信可验证的证据。
- 人物弧：怀疑林国强 → 承认其配合但保持程序 → 识别栽赃链条 → 完成抓捕与移送。
- 台词风格：中性、准确。典型句：“你知道什么不重要，你能证明什么才重要。”

## 群像使用规则

- 单集核心人物不超过4人。
- 一段5—15秒镜头原则上不超过3张人物参考图。
- 新人物首次出现必须先建立标准全身图或三视图，再生成多人构图。
- 情绪冲突必须落到具体事务：钱、合同、孩子、货物、安全、证据；避免纯误会拖集数。
