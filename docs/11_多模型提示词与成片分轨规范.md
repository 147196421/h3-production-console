# 多模型提示词与成片分轨规范

## 1. 核心原则

制作台中的“剧情任务”是共同底稿，包含人物、事件、按秒动作、对白和结尾状态；“模型提示词”和“生成结果”按H3、Grok分别处理。切换模型不会改写剧情事实，只会切换模型专用执行要求、当前模型的任务状态、成片、首帧和尾帧。

禁止把两个模型的结果当成同一条连续轨道。H3镜头默认只继承H3上一镜尾帧，Grok镜头默认只继承Grok上一镜尾帧。

## 2. 前台操作

1. 在制作台顶部选择H3或Grok。
2. 打开镜头后，复制当前模型显示的“专业单框提示词”。
3. 下载参考图，在提示词每个`@文件名`出现的位置选择同名图片。
4. 在第三方生成平台选择与任务一致的5秒、10秒或15秒时长和9:16比例。
5. 生成完成后回到制作台，确认顶部仍是刚才使用的模型，再上传视频。
6. 系统把该视频和首尾帧写入当前模型分轨；切换到另一模型不会看到或覆盖这份结果。

## 3. 提示词差异

两种提示词必须共同保留：剧情因果、按秒时间轴、人物与场景参考图、结尾状态、年代限制、3D写实国漫视觉规范。

H3版本强调严格分段、稳定构图、身份一致和避免复杂突变，适合让动作按秒可靠落地。Grok版本强调一条连续电影镜头中的动作惯性、自然反应停顿、微表情和次级运动，但同样不得擅自改变人物、服装、场景与年代。

模型差异不是只替换“H3/Grok”字样；制作台会为EP01每个镜头注入当前模型专用运镜，再加入模型级执行重点和质量控制。

### EP01两套运镜基调

| 镜头 | H3版本 | Grok版本 |
|---|---|---|
| C01惊醒 | 固定床侧中景、一次推近、稳定半坐结尾 | 冲击式推近、轻微呼吸感手持、自然稳定结尾 |
| C02日历 | 稳定横移、单次拉焦、分段读取信息 | 眼神驱动横移、弧线回脸、连续后退容纳下床 |
| C03入门 | 原机位右摇、轻微后拉、三人站稳 | 继承运动惯性、随视线右摇、平滑后移建立纵深 |
| C04小满 | 儿童眼平固定近景、极慢推近 | 前景遮挡、焦点呼吸、随儿童后缩轻推 |
| C05请求 | 固定三人中景、动作严格先后 | 克制半弧侧移、对白反应与视线引导 |
| C06收音机 | 稳定道具近景、接触后才发光 | 微距跟手、轻环绕、景深与反射渐变 |
| C07记忆 | 四个清晰短插入、亮点匹配切 | 同方向运动蒙太奇、光晕无缝转场 |
| C08机会 | 声音桥硬切、床边稳定中景 | 声音先入、从道具摇回床边、前中后景 |
| C09沉默 | 固定三人同框、依次转头 | 缓慢弧形推进、逐个捕捉微反应 |
| C10新闻 | 收音机特写、极慢推近并稳住 | 视线匹配切、微距缓推、轻焦点呼吸 |

上述差异只能改变表达方式，不能改变人物何时出现、从哪里进入、手中拿什么、对白意思和镜头结尾状态。

## 4. 文件与数据隔离

- H3成片：`data/videos/h3/EPxx/EPxx_Cxx_H3.*`
- Grok成片：`data/videos/grok/EPxx/EPxx_Cxx_GROK.*`
- H3帧：`data/frames/h3/EPxx/EPxx_Cxx_H3_首帧.jpg`、`EPxx_Cxx_H3_尾帧.jpg`
- Grok帧：`data/frames/grok/EPxx/EPxx_Cxx_GROK_首帧.jpg`、`EPxx_Cxx_GROK_尾帧.jpg`
- SQLite表`task_outputs`以`task_id + model`为唯一键，分别记录路径、提取时间和任务状态。

旧版本已有的单轨视频会迁移为H3分轨，不会自动复制成Grok结果。

若用户之前只完成了EP01-C01和C02的H3版本，后来决定全片改用Grok，应切到Grok后从C01重新生成。后台会把Grok的C01、C02视为“待生成”，原H3成片保留在H3分轨中备查，不影响Grok从头建立连续尾帧链。

## 5. 尾帧衔接

若下一镜标记为“尾帧续拍”，当前模型上一镜上传完成后，下一镜参考素材会自动出现带模型后缀的真实尾帧，并且提示词中的引用同步变为对应文件名，例如：

- H3：`@EP01_C02_H3_尾帧.jpg`
- Grok：`@EP01_C02_GROK_尾帧.jpg`

若下一镜是“新首帧”或新机位硬切，不强制上传上一镜尾帧，但仍必须继承上一镜剧情输出状态，包括房间里已有的人、手中道具、站位方向、时间和光线。模型切换不能成为省略人物入场或道具来源的理由。

## 6. AI接管检查项

新AI扩写下一集或修订提示词前，必须完成以下检查：

1. 阅读项目交接总览、60集大纲、人物圣经、视觉规范、连续性文档和本规范。
2. 询问或确认本轮使用H3还是Grok。
3. 在后台查看该模型分轨最后一个通过验收的任务、成片和真实尾帧。
4. 不得根据另一模型“已完成”的状态推定当前模型也已完成。
5. 只有在用户明确要求跨模型衔接且人工验收画面可接时，才能手动使用另一模型尾帧；必须记录原因，系统默认不自动执行。
